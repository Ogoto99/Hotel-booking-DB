# Hotel Booking Database

## Project Overview

This project is a relational database designed to manage hotel booking operations.

The system manages hotels, rooms, room types, guests, bookings, payments, hotel services and staff.

## Database Domain

Hotel Booking and Management System.

## Main Features

- Hotel management
- Room management
- Guest management
- Hotel bookings
- Payment tracking
- Hotel services
- Staff management
- Booking-service management

## Database Tables

1. hotels
2. room_types
3. rooms
4. guests
5. bookings
6. payments
7. services
8. booking_services
9. staff
